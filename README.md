# IVA Автовход

Android-приложение для быстрого входа в митинги IVA Connect. Ярлык на рабочем столе открывает IVA Connect
и сам проходит экраны входа: вход по ID, подтверждение митинга, имя гостя, пароль.

Без рекламы, без доступа в интернет, без сторонних библиотек.

## Как работает

1. Касание по ярлыку комнаты (или по «Войти» в приложении) запускает IVA Connect с первого экрана.
2. Служба специальных возможностей в течение 2 минут ведёт приложение по шагам:
   **Enter with ID** → ID комнаты → **Join** → имя гостя → **Join** → пароль митинга → **Join**.
   Русские надписи тех же кнопок тоже распознаются.
3. Служба работает только внутри IVA Connect и только после запуска с ярлыка. В остальное время она ничего не делает.

Пароли комнат хранятся зашифрованными ключом из Android Keystore. Резервное копирование данных приложения выключено.

## Установка

1. Скачайте APK из [Releases](../../releases) и откройте его на телефоне.
2. Настройки → Приложения → IVA Автовход → ⋮ → **Разрешить ограниченные настройки**.
   Без этого Android 13+ не даст включить службу для приложения не из магазина.
3. Настройки → Специальные возможности → Установленные приложения → IVA Автовход → включить.

После обновления APK Android может выключить службу. Тогда включите её снова.

## Настройка

- **Ваше имя в митинге** — имя, с которым вы входите как гость.
- **Комнаты** — список. «Войти» справа запускает вход, касание по комнате открывает её настройки:
  название, сервер, ID, пароль, ярлык на рабочий стол.
- **Сохранённые серверы** подставляются в поле «Сервер» одним касанием.
- **Ещё** — какое приложение IVA открывать и на каком экране автовход остановился в прошлый раз.

## Сборка

Обычный Android-проект на Gradle: откройте папку в Android Studio или выполните `./gradlew assembleRelease`.
Подпись релизной сборки: [Sign your app](https://developer.android.com/studio/publish/app-signing).
