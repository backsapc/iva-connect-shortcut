# Изменения

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии: [SemVer](https://semver.org/lang/ru/).

## [2.3] - 2026-11-24

### Добавлено

- Экран адреса сервера, который IVA Connect показывает после сброса настроек: автовход вписывает
  сервер комнаты (или последний сохранённый) и нажимает «Continue».

## [2.2] - 2026-11-23

Первый публичный выпуск.

### Возможности

- Вход в митинг IVA Connect в одно касание: с ярлыка на рабочем столе или кнопкой «Войти» в приложении.
- Автоматически проходит экраны IVA Connect: вход по ID, подтверждение митинга, имя гостя, пароль.
  Понимает английский и русский интерфейс IVA.
- Список комнат: касание по комнате открывает её настройки, комнат может быть сколько угодно.
- Сохранённые серверы подставляются в поле «Сервер» одним касанием.
- Ярлык каждой комнаты на рабочий стол, все комнаты есть в меню по долгому нажатию на иконку.
- Светлая и тёмная тема.

### Безопасность

- Пароли комнат зашифрованы ключом из Android Keystore.
- Нет доступа в интернет, нет рекламы и сторонних библиотек.
- Служба работает только внутри IVA Connect и только 2 минуты после запуска с ярлыка.
